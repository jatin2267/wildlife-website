STEP 3: Design Requirements to Fulfill

Requirement	                                    Plan to Implement

->  Responsive Design	                        Use Flexbox/Grid + 3 media queries for desktop, tablet, mobile
->  External CSS	                            style.css inside css/ folder
->  Font Icons	                                Use FontAwesome for social links/icons
->  Web Fonts	                                Use Google Fonts or @font-face
->  At least 5 images	                        Include lion, elephant, safari jeep, landscapes, etc.
->  Use of <table>, <ul>, <ol>, etc	            Show safari package pricing, top animals, or travel checklist
->  At least 1 JavaScript feature	            Add a basic image slider or responsive menu toggle
->  HTML Form	                                In contact.html (e.g., Name, Email, Package selection, etc.)
->  No CSS inline or embedded	                All styling via external CSS only
